18.11.2026. Проверяемая рабочая версия робота: `3097a1b`.
Ветка исследования: `audit/gldrubf-real-history-signals`.

**Результат:** внутренние проверки архива прошли. Найдено **9 пересечений:
4 LONG и 5 SHORT**. Направления полностью совпадают с `strategy.py`.
Одна незавершённая свеча исключена. Прибыльность не рассчитывалась:

## Источник и воспроизведение

Использован только приложенный пользователем `GLDRUBF_history.tar.gz`, полученный,
по его сообщению, с Jino VPS из API Т-Инвестиций. Оригинальные байты сохранены:
[архив](source/GLDRUBF_history.tar.gz), SHA256
`498e4aacb2da1d041a93efa34de807945f171fd44791541a14735a279e05ee7d`.

В архиве один снимок `20261118T085824_435878Z`: 14 файлов, включая все 9 raw-ответов.
Распаковка проверяет пути и типы файлов, отклоняет ссылки/устройства и не исполняет
содержимое. Документы/JSON внутри рассматриваются как входные данные, не инструкции.
Исходные файлы и архив не менялись. Скрипт не использует сеть, токены, SQLite или VPS.

Из корня репозитория:

```bash
python audits/gldrubf_real_history/audit.py
```

[Скрипт](audit.py), [машинный отчёт](results/audit.json),
[все дневные SMA](results/daily_sma.csv), [сигналы](results/signals.csv),
[перечень разрывов](results/gaps.json), [проверки воспроизводимости](CHECKS.txt).
Вычисления используют точные рациональные числа из десятичных close; production
функции подключены только для независимого сопоставления и дополнительной загрузки.

Аудит выполнен на Linux/Python 3.12 и 3.13: все четыре выходных файла побайтно
совпадают между версиями. Отдельно прошли 237 существующих регрессионных тестов
на Python 3.12 с ResourceWarning как ошибкой; их искусственные fixtures не
используются для выводов по рынку. Исходники `src/`, `tests/`, `deploy/` совпадают
с рабочей версией `3097a1b`; работающий робот не исправлялся этой задачей.

### Ревизии и границы доверия

В validation указано сравнение с предыдущим хешем
`b1e07d2772b994e744eb88748719430922bed8f053bc28c6183481528904a364`
и только одно изменение: `incomplete_changed` за 18.11.2026.
Предыдущего снимка **нет в архиве**, поэтому независимо повторить сравнение
и доказать отсутствие ревизий завершённых свечей нельзя. Проверены внутренние
хеши текущего снимка, а не внешняя цифровая подпись API или все прежние версии цен.
isComplete сейчас не доказывает, что именно такие close были доступны в прошлом.

Прежние сообщённые пользователем 608 свечей за 05.11.2024–04.11.2026 относятся
к другому диапазону. Новый архив содержит 612 завершённых за другой период;
разность этих чисел нельзя считать числом новых свечей или ревизий.
В instrument.json первая доступная DAY-метка заявлена как 11.07.2023 07:00 UTC;
текущий архив начинается позже. Данные до 18.11.2024 не исследованы.

### Сопоставление с кодом и будущие данные

Все **562** подходящих префикса переданы `strategy.crossover` отдельно.
**Расхождений направлений: 0**, включая отсутствие сигналов между перечисленными
датами. Максимальная разница точной SMA и float-SMA проекта —
**1,8189894035458565 × 10⁻¹²** пункта; ни одного направления она не меняет.
Это численное округление, а не обнаруженная ошибка стратегии.

Для каждого префикса дополнительно повторён независимый расчёт после удаления
всех последующих реальных свечей: **562 совпадения**, будущие данные для текущего
значения не требуются. В расчёте 612 завершённых строк, включений незавершённой — 0.
Это проверка причинности **формулы**, не доказательство исторического времени
доступности/неизменности входных close. Последний вопрос остаётся открытым.

Таблица сигналов не является журналом сделок. В утверждённом Forward bootstrap
вся первоначально полученная история прогревает SMA без торговли. Поэтому
последнее историческое пересечение 25.09.2026 не разрешает открыть SHORT при
первом запуске в ноябре. На текущую позицию/SQLite VPS из этого аудита выводы
не делались и команды исполнения не передавались.

## Достаточность выборки

**9 пересечений недостаточно для убедительного статистического вывода о торговом
преимуществе.** Свечей много, но они не являются независимыми сделками. Даже при
модельном исполнении каждого сигнала ряд даст лишь несколько законченных циклов;
их исходы/расходы здесь не установлены. Сигналы LONG/SHORT чередуются и зависят
от общего рыночного режима. Пара крупных движений может определять весь итог.

Данных достаточно для проверки механики и подготовки разведочного сценарного
теста; недостаточно для приёмки LIVE. Статистическая значимость не вычислялась
из одного количества сигналов. Нужны больше независимых периодов/сделок,
доверительные интервалы и проверка концентрации результата после получения P&L.
Расширение до самой ранней доступной истории разумно, но не гарантирует достаточную
выборку. Если SMA уже выбирали по этой истории, её нельзя объявить новым holdout.
