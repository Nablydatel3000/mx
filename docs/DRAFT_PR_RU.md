## Описание

Дополнение: [TradingSchedules HTTP 400](TRADING_SCHEDULES_400_RU.md).
Подтверждено документированное отсутствие прошлых расписаний: исторический day
fetch останавливается без выдуманного календаря. Добавлены безопасные числовые
коды API и диагностика реальных exchange/from/to с текущими контрольными запросами.
PAPER/стратегия не менялись; исторический календарь остаётся внешним требованием.

Дополнение: [диагностика авторизованного HTTP 502](API_502_DIAGNOSTIC_RU.md).
Отдельный Windows launcher сравнивает urllib и curl.exe одним POST FindInstrument
на клиент. Токен вводится скрыто и передаётся curl только через stdin; наружу
выводятся клиент, статус и категория. TLS сохранён; SMA20/50 и PAPER не меняются.
Реальное сравнение на Windows с одним токеном ещё требуется; одинаковые 502
не считаются доказательством дефекта Python.

Дополнение: [диагностика Invalid API JSON](API_HTTP_DIAGNOSTICS_RU.md).
REST-хост сверен с официальным OpenAPI, ошибки безопасно сообщают метод, статус,
Content-Type и категорию; HTTP-ответы освобождаются, сохранены TLS/read-only защиты.
82 теста прошли на Linux/Python 3.12 и 3.13. Пользователь сообщил об успешных 68
тестах прежней версии на Windows; новый HTTP-клиент с настоящим API там ещё
предстоит проверить. Фактический метод прежнего сбоя по старому сообщению неизвестен.

Дополнение 2026-11-05: [исправление Windows SQLite / WinError 32](WINDOWS_SQLITE_FIX_RU.md).
Явное закрытие SQLite-соединений без изменения SMA20/50; контроль ресурсов выявил
13 тестов с утечками до исправления. После исправления 68 тестов прошли на Linux / Python
3.12 и 3.13. Добавлен Windows/Linux CI; успешное выполнение Windows CI пока не
подтверждено. LIVE и merge не выполнялись.

Прототип сохранял целевую позицию по reference close и не имел исполнения/P&L. Эта поставка добавляет read-only рыночные данные Т-Инвестиций и отдельный транзакционный PAPER-движок с исполнением только по более позднему наблюдению цены. SMA20/50 и максимум один LONG/SHORT-контракт сохранены.

Реализованы UID GLDRUBF, официальный календарь и завершённые свечи, обработка API-ошибок/пропусков, Decimal P&L, комиссии/проскальзывание и настраиваемая дневная модель финансирования, SQLite recovery/idempotence и Windows launchers. Клиент ограничен read-only allowlist; LIVE, реальные заявки, deployment и оптимизация не реализованы.

Фактически прошли исходные 6 и расширенные 62 теста на Linux, compileall и CLI-help. Финальный suite проверен в чистой копии публикуемых файлов. Журнал: docs/TEST_RESULTS.txt. Аудит, изменения, Windows-инструкция и ограничения: docs/AUDIT_AND_IMPLEMENTATION_RU.md и README.md.
